# beaf GN drive

An original, self-contained 3D stunt-driving game for the browser. It uses WebGL directly and does not require downloaded libraries, a build step, or a local server.

## Play

Open `index.html` in a modern browser with WebGL enabled.

## Controls

| Key | Action |
| --- | --- |
| W / Up arrow | Accelerate; pitch forward in the air |
| S / Down arrow | Brake or reverse; pitch backward in the air |
| A / Left arrow | Steer left; roll left in the air |
| D / Right arrow | Steer right; roll right in the air |
| Space | Handbrake and drift |
| Shift + W | Nitro boost |
| C | Cycle camera views |
| P | Pause or resume |
| R | Reset the run |

Build speed, launch from ramps, pass through the arena gates, and land tricks to score points. Impacts affect the car's handling and visible bodywork.
